# Flutter Droid

Droid móvil especializado en Flutter usando las skills de `flutter/skills`.

## Descripción

Enfocado en tareas end-to-end de apps Flutter: setup, arquitectura, UI, datos, tests y ejecución.

## Modelo

`inherit` - Usa el modelo por defecto

## Uso

```typescript
Task({
  subagent_type: "flutter-droid",
  description: "Implementar feature Flutter",
  prompt: "Agrega autenticación y tests en mi app Flutter"
})
```
